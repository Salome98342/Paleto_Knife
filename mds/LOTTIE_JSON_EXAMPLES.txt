# GUÍA PARA PERSONALIZAR ESTOS JSON
# ============================================================================

"""
CAMBIAR COLORES:

Busca secciones como:
"c": { "a": 0, "k": [ 0.8, 0.6, 0.2, 1 ] }

El formato es [R, G, B, A] donde cada valor es 0.0-1.0

Ejemplos:
- ORO (#D4A574):      [0.83, 0.65, 0.45, 1.0]
- NARANJA (#FF6B00):  [1.0, 0.42, 0.0, 1.0]
- ROJO (#CC3333):     [0.8, 0.2, 0.2, 1.0]
- BLANCO (#FFFFFF):   [1.0, 1.0, 1.0, 1.0]

CAMBIAR DURACIÓN:

Cambia "op" (operation point = último frame):
- 2 segundos @ 30 fps = 60 frames
- 0.5 segundos @ 30 fps = 15 frames
- 0.8 segundos @ 30 fps = 24 frames

CAMBIAR TAMAÑO:

Busca:
"s": { "a": 0, "k": [ 120, 80 ] }

Primer número = ancho
Segundo número = alto

CAMBIAR POSICIÓN:

Busca:
"p": { "a": 0, "k": [ 0, 0 ] }

Primer número = X (left-right)
Segundo número = Y (up-down)
"""
